### Projects

#### [CampusXChange](https://github.com/nayan-m15/Campus-Marketplace) · [Live Demo](https://mango-bay-0edf29110.7.azurestaticapps.net/)
*Campus Marketplace — Team of 4*

A secondhand marketplace for students to buy, sell, or trade items safely within a university context, with separate admin and staff dashboards to manage facilities, bookings, and marketplace operations. Integrated PayFast for payments, Brevo for email notifications, and SerpAPI for product search. Deployed on Azure Static Web Apps with Git-based version control.

- **Tech used:** React, Vite, CSS, Supabase, Azure Static Web Apps, PayFast, Brevo, SerpAPI

#### [Gaffer](https://github.com/nayan-m15/Gaffer) · [Live Demo](https://gaffer-virid.vercel.app/)
*Coaching Platform — Team of 6 · In Development*

A full-stack coaching platform for amateur football teams to manage rosters, schedule fixtures, and record live match events, with player statistics automatically derived from event logs. Offline integration using PowerSync with background synchronisation and duplicate-entry detection. Role-based access control for Coach, Assistant, and Athlete users with Zod-validated APIs documented via Swagger/OpenAPI.

- **Tech used:** React 19, TypeScript, TanStack Query, shadcn/ui, NestJS, Drizzle ORM, Neon PostgreSQL, PowerSync

#### Human Activity Recognition
*ML Group Project — Team of 4*

An end-to-end machine learning pipeline to identify six human activities from multivariate time-series data collected through a wearable sensor system. Extracted over 1,470 features per sample including statistical, frequency-domain FFT, autocorrelation, and cross-sensor correlation features. Achieved a Macro-F1 of 0.797 ± 0.021 using a tuned LightGBM model with stratified 5-fold cross-validation.

- **Tech used:** Python, NumPy, Pandas, Scikit-learn, LightGBM, Kaggle

#### [Crafted Interiors](https://www.craftedinteriors.co.za/)
*Carpentry Business Website*

Contributed to the development and refinement of a professional website for a bespoke carpentry and interiors company, working within an existing React codebase. Redesigned the About page and reworked the hero section video to improve the overall user experience.

- **Tech used:** React, TypeScript, Vite, Tailwind CSS

#### [GrubFlow](https://github.com/nayan-m15/Project_GrubFlow)
*Restaurant Order Tracker — Team of 4*

A restaurant order tracking Android application which lets staff track orders in real time. Features include user login, live order status updates, and an admin dashboard. Built with Android Studio with a PHP backend — a purely academic application, never used by actual restaurant staff.

- **Tech used:** Java, Android Studio, PHP, MySQL
